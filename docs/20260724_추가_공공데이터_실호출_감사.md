> 보안: 인증키 값은 기록하지 않음

## 결론

추가 승인된 세 API는 모두 같은 공공데이터 인증키로 실호출에 성공했고, MVP의 실데이터 흐름에 연결했다. 이후 공식 V3 기술명세서의 코드표를 확보해 배수·유효토심·표토토성·토지이용·밭 적성등급·저해요인을 해석했다. 밭 적성등급은 v4 주판정에, 배수는 선택 기간 위험에 사용하며 중복 감점하지 않는다. 최근 농업기상은 최근접 관측소의 공간 대표성을 검증하기 전까지 설명 근거로만 유지한다.

## 재현한 전체 흐름

1. 지도 좌표의 반경 1km 팜맵 후보 356개 조회
2. 지번 검색으로 `대관령면 279-15전` 선택
3. PNU `5176038024102790015`, 팜맵 ID `427603802400956` 정합 확인
4. 같은 PNU로 토양검정 화학성 V2와 토양특성 V3 조회
5. 농업기상 관측지점 목록에서 거리 기준 최근접 지점 선택
6. 선택 지점의 최근 7일 기본 관측데이터 조회
7. 기상청 단기예보와 함께 분석 결과 화면에 출처·기준기간·한계 표시

브라우저 전체 흐름 결과는 `공공데이터 연결`, 연결 소스 `4/4`, 경고 없음으로 확인했다.
