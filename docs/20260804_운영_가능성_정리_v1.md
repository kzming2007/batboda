## 1. 지금 운영되고 있다 **[사실]**

배포된 웹에서 외부 접속으로 전 과정이 돕니다. **2026-08-04 16:40, 단계별로 3회씩 재고 중간값**입니다.

```
https://batboda.vercel.app        시연 조합: 대관령면 85-61전 · 상추 · 3일

농지 후보 조회 (반경 1km, 356건)      1.4초
필지 경계 조회                       1.0초

설명   AI 설명 · Gemini 3.5 Flash · 검사 통과 (02·04 다섯 항목 전부)
```

**저장본이 없는 조합** — 심사위원이 임의의 필지를 골랐을 때입니다. 실시간 생성 호출이 붙습니다.

```

설명   AI 설명 · Gemini 3.5 Flash · 실시간 생성 · 검사 통과
```

**어느 필지를 눌러도 5초 안에 검사를 통과한 AI 설명이 나옵니다.**

> **숫자를 인용할 때** — 위는 **API 응답 시간**입니다. 사람이 목록을 훑어 지번을 찾는 시간은 빠져 있습니다. 화면을 조작하는 시간까지 포함한 체감은 더 깁니다(원격 제어 환경에서 15초 관측). 발표에서는 **분석 약 4초, 실시간 생성 포함 5초**로 말하는 것이 정확합니다.

**데모용 로컬 실행이 아닙니다.** 주소만 있으면 누구나 지금 열어 자기 농지를 조회할 수 있습니다.

## 2. 누가 쓰는가

| 사용자 | 언제 | 무엇을 얻나 |
|---|---|---|
| **예비·초기 귀농인** | 농지를 계약하기 전, 첫 작물을 정할 때 | 그 필지의 토양이 그 작물 기준에 맞는지, 가까운 기간에 뭘 먼저 해야 하는지 |
| **지자체 귀농귀촌센터** | 상담 창구에서 | 상담자가 근거를 화면으로 보여주며 설명. 출처·기준시각이 화면에 있어 책임 소재가 분명 |
| **농협·영농 컨설팅** | 작목 전환 상담 | 같은 필지의 작물별 판정을 비교해 제시 |

**[제안]** 첫 진입은 개인 사용자지만, **실제 운영 주체는 상담 창구**라고 봅니다. 귀농인은 1년에 몇 번 쓰지만 센터는 매일 씁니다.

## 4. 외부 장애에 견디는 구조 **[사실]**

운영 가능성의 핵심은 "잘 될 때"가 아니라 "안 될 때"입니다.

| 상황 | 동작 | 화면 표시 |
|---|---|---|
| 정상 | 공공데이터 4갈래 실시간 | `실시간 연결 4/4` |
| 일부 API 실패 | 실패한 소스만 검증 스냅샷으로 대체 | `검증 스냅샷` + 실패 사유(HTTP 코드) |
| 팜맵 전면 실패 | 검증 스냅샷 필지로 확정→분석까지 진행 | `검증 스냅샷` + 실패 사유 |
| 생성형 AI 실패·한도 초과 | 같은 근거로 만든 규칙 문장으로 대체 | `AI 호출이 안 되어 규칙 문장을 표시` |
| AI 문장이 규칙 위반 | 검사가 차단하고 규칙 문장으로 대체 | 걸린 이유를 화면에 표시 |
| 네트워크 전면 차단 | 시연 자료로 흐름 유지 | `시연 자료` |

**세 상태를 화면에서 구분합니다** — `실시간` / `검증 스냅샷` / `시연 자료`. 대체를 실시간처럼 보이게 하지 않습니다.

2026-08-03에 공공데이터 인증이 실제로 막혔을 때(HTTP 401) 이 경로로 판단까지 이어지는 것을 확인했습니다. **가정이 아니라 겪은 일입니다.**

## 5. 후속 고도화 방향

지금 못 하는 것을 순서대로 적었습니다. 각 항목은 화면의 「한계」에 이미 공개돼 있습니다.

### 1단계 — 확인 기간 확대

지금은 단기예보 범위인 **3일**까지입니다. 중기예보(10일)를 연결하면 파종 시기 판단까지 다룰 수 있습니다. **[미확인]** 중기예보 API의 격자 단위가 단기예보와 달라 매핑 확인이 선행돼야 합니다.

### 2단계 — 작물 확대

지금은 5종입니다. **공식 기준 장부를 판·쪽수까지 확보한 작물만** 추가합니다. 근거 없는 확장은 하지 않습니다. 농업기술길잡이 기준으로 엽채류·근채류부터 넓히는 것이 현실적입니다.

### 3단계 — 토양 자료가 없는 필지 보완

대관령 반경 1km에서 토양검정 값이 나오는 필지는 **18건, 7.0%**입니다. 지금은 산도 없이 판정하고 신뢰 표시를 낮춥니다. 인접 필지 값을 **출처를 구분해** 참고로 보여주는 방향을 검토합니다. 같은 필지 값처럼 표시하지 않는 것이 조건입니다.

### 4단계 — 정확도 검증

**아직 하지 않았습니다.** 현장 수확 자료와 대조한 예측 성능 평가가 없습니다. 지자체 시범 운영으로 실제 재배 결과를 모으는 것이 전제입니다. 그전까지는 "판단을 돕는 참고 도구"로만 말합니다.

## 6. 지금의 한계를 그대로 적는다 **[사실]**

- 토양검정 이력이 있는 필지가 적습니다 (대관령 반경 1km 기준 7.0%)
- 확인 기간이 3일입니다
- 최근 관측은 농지에서 떨어진 관측소 기록입니다 (예: 6.45km)
- 작물 5종입니다
- **정확도를 검증하지 않았습니다**
- 필지 경계는 팜맵 PNU 조회에서 식별자가 일치할 때만 표시합니다. 없으면 그리지 않습니다

이 목록은 화면과 문서에 같은 내용으로 있습니다. **못 하는 것을 숨기지 않는 것이 이 서비스의 설계 원칙입니다.**
