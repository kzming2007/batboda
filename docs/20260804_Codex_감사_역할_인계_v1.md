## 역할 경계

**Codex 산출물은 다섯으로 한정한다** — 예상 점수, 근거 공백, 5분 발표 구조, 1분 데모, 예상 질문.

**코드와 발표자료를 수정하지 않는다.** 브랜치가 있어 되돌릴 수는 있지만, 아래 두 파일은
오늘 전면 재작성했고 지금도 손대는 중이라 양쪽이 같이 만지면 합칠 때 손으로 풀어야 한다.

```

prototype/codex-mvp/components/FarmDecisionApp.tsx (1,700행 · 눈금 렌더 추가)
```

`docs/`와 소개서·대본은 읽기만 하면 충돌이 없다. **평가 결과는 새 문서로 쓰고 기존 문서를
고치지 않는다.**

## 3. 보류한 항목과 이유 **[사실]**

| 항목 | 왜 보류했나 |
|---|---|
| **인쇄 3쪽** | 이 앱은 `view` 상태에 따라 **한 번에 한 화면만 DOM에 둔다.** 03을 보면서 인쇄하면 02·04는 애초에 문서에 없어서 3쪽이 안 나온다. 셋을 동시에 렌더한 뒤 화면에서만 하나씩 보이게 해야 하고, 그 변경은 `[hidden]`과 `display`가 얽힌 자리를 건드린다. **지금 되는 것은 열려 있는 화면을 종이용으로 정리하는 것까지다** |
| **마인드맵 (`origin/ui-mindmap`)** | 동기가 02를 마인드맵으로 재구성한 갈래(`6c60688`). 그 브랜치의 CSS는 옛 파일 기준이라 그대로 합칠 수 없다. **마크업·상호작용 아이디어는 쓰고 스타일은 새 구조 안에서 다시 짜기로 팀에서 정했다.** 방사형 배치 시안을 먼저 본다 |
| **인접 필지 보간 pH** | 표시 전용으로만 쓸 수 있고 판정에 넣으면 없는 값을 지어내는 것이 된다. `못 하는 것을 먼저 말한다`는 원칙과 충돌해 넣지 않았다 |
| **김제 프리셋 추가** | 실시간 757건 확인은 됐다. 시연 경로가 이미 셋이라 늘릴 이유가 약하다 |
| **사용자 테스트** | 남은 시간에 표본을 모을 수 없다. 없는 것을 있다고 말하지 않는다 |
| **`tests/report.test.ts:200` 타입 오류** | 동기의 `0689147`부터 있던 것이고 프로덕션 빌드에 영향이 없다. D-day에 남의 테스트를 건드리지 않는다 |
| **`prototype/codex-mvp` 폴더명** | 본선 이후로 미뤘다. 지금 옮기면 배포 설정이 흔들린다 |

> 갈라 주면 좋겠다. 대본 v1은 한계를 40초 배정해 스스로 먼저 말하는 구조다.

## 4. 발표에서 보여줄 수 있는 대표 데모 경로 **[사실]**

배포본 `https://batboda.vercel.app` · 로컬 `npm run dev` (포트 3000).

### 경로 A — 실시간 · 주력 (오늘 실제로 통과)

```
1. 대표 농지 `평창 대관령` 또는 `경기 이천` 클릭
2. `주변 농지 찾기`   → 실시간 후보 (대관령 8건 / 이천 468건 · 반경 1km)
3. 지번 검색 후 후보 클릭 → 지도에 필지 경계가 그려진다   ← 첫 번째 정점
4. 작물 선택 → `이 농지 분석하기`
5. 02 판정서 → 03 자세한 근거 → 04 쉬운 말 보고서
```

**오늘 실측한 조합 두 개.**

| 조합 | 결과 |
|---|---|
| 이천 유방동 870답 · **사과** | `현장 확인 필요` / 위험 높음 · 근거 **과수 적성등급 4급지** · pH 자료 없음 |
| 이천 유방동 870답 · **상추** | `현장 확인 필요` / 위험 높음 · 근거 **밭 적성등급 3급지** |
| 대관령 294-7전 · **사과** | `조건부 적합` · pH 6.2 (띠 안) · 기온 31.8℃ (띠 밖) · 눈금 둘 다 표시됨 |

**같은 필지에서 작물만 바꿔 근거가 갈리는 것을 보여줄 수 있다.** 심사위원에게 작물
선택권을 주는 시연에 그대로 쓸 수 있는 조합이다.

**AI 경로 확인** — `Gemini 3.5 Flash · 실시간 생성 · 검사 통과`로 동작 중이고, 04 문장이
`과수 적성등급(그 용도로 쓰기에 얼마나 맞는지 나눈 공식 등급)`으로 나온다.

### 경로 B — 대체 자료 (실패 시연용)

`실제 공공데이터로 조회` 체크를 끄면 저장된 검증 스냅샷으로 판단까지 이어지고,
화면에 **`검증 스냅샷`**이라고 적힌다. 실시간 / 검증 스냅샷 / 시연 자료 세 상태를 구분한다.

### 알아 둘 제약 **[사실]**

- 04 쉬운 말 보고서는 **pH와 적성등급이 모두 조회된 필지에서만** 열린다.

## 부록 — 이 채팅이 오늘 틀렸다가 고친 것 **[사실]**

같은 실수를 반복하지 않게 적어 둔다. Codex가 감사할 때 참고가 된다.

- **서브에이전트가 잘못된 저장소(`해커톤`)에서 작업**했다. 그 결과 "`soilUseKind`가 없다"고
  보고했는데 그건 동결된 트리라서였다. 원상복구하고 올바른 저장소에서 다시 했다.
  **저장소 경로를 절대경로로 확인하는 것이 필요하다**
- **`.analyze-button:disabled` 대비가 1.16:1로 측정**됐다. 실제로는 브라우저 창이
  컴포지팅되지 않아 트랜지션이 시작값에 멈춰 있던 것이었다. 트랜지션을 끄면 정상.
  **숨은 창에서 잰 애니메이션 값은 신뢰할 수 없다**
- **테스트 기대값을 측정 없이 적어** 한 건 실패했다. 다른 필지의 결과를 옮겨 적었다
- **상태색 셋이 모두 대비 미달**이었다. 이전에 보조 본문 색 하나를 고치면서 상태색은
  재지 않았다. `--watch`는 흰 바탕에서도 3.87:1이었다
