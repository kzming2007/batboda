`.favorite-remove`는 기본 `opacity`가 낮게 설정되어 있고 hover/focus-within/focus-visible 세 경로로만 드러난다. 세 규칙 중 하나라도 빠지면 키보드 사용자가 즐겨찾기를 삭제할 수 없다.

### 6.9 그 밖의 load-bearing 사항

- **`hidden` 속성을 쓰지 않는 이유가 CSS에 있다.** `.workbench { display: grid }`(248)가 브라우저 기본 `[hidden] { display: none }`을 명시도로 이겨서, 다른 페이지에서도 지도가 남았다(TSX 419–424). 재작성에서 `.workbench`에 `display`를 남긴다면 이 사실이 유지된다.
- **`html`·`body`의 `background: var(--field-paper)`**(77, 83) 두 곳 모두 필요하다. 하나만 두면 오버스크롤 영역 색이 달라진다.
- **`body { word-break: keep-all }`**(85) — 한글 어절 단위 줄바꿈. 이것이 빠지면 판정 문장이 낱자 단위로 끊긴다.
- **`.sheet-detail-body` 접두사 규칙군**(2282–2470, 3422–3520, 3717–3760). 03·04 화면의 실제 값 대부분이 여기서 나온다. 접두사 없는 원본 규칙(1333–1520 부근)은 대부분 이 규칙에 덮혀 화면에 나타나지 않는다.
- **`.factor-value::before` / `.factor-target::before` / `.factor-impact::before`**(3733–3735, [MQ 820]) — 모바일에서 표 머리를 대신하는 라벨. `content` 값이 여기에만 있다.
- **`.map-parcel-card { bottom: 56px }`**(323) — 좌표 칩(`.map-caption`)과 겹치지 않도록 계산된 값. 주석에 명시(322).
- **`.factor-signal { align-self: start; margin-top: 7px }`**(3046–3047) — 값·기준이 줄바꿈될 때 점을 행 중앙이 아니라 첫 줄에 맞추는 값. 주석에 명시(3043).
- **`min-width: 0`**(`.climate-observation-grid > div` @1033) — grid 자식이 내용 길이로 늘어나 부모를 밀지 않게 막는다.
- **`overflow-wrap: anywhere`** 4곳(986 `.parcel-facts dd`, 1011 `.soil-profile-band dd`, 1251 `.score-ledger > code`, 3419, 3674) — PNU·팜맵 ID·산식 문자열이 셀을 넘기지 않게 한다.
- **`.parcel-candidate-list strong { overflow: visible; text-overflow: clip }`**(3671–3672) — 3664 주석에 "지번 대조가 이 화면의 목적"이라 적혀 있다. 690의 `text-overflow: ellipsis`를 되돌린 규칙이다. 지번이 잘리면 이 화면의 기능이 사라진다.
