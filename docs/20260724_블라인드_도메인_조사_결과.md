# 농업환경·병해 위험 도메인 조사 결과 (사과·배·오이·감자·상추)

## 1. 핵심 함정과 의사결정 포인트 (요약)

1. **공식 "재배적지" 등급표는 과수(사과·배) 중심**이다. arccas(농업·농촌 기후정보시스템)에는 사과·배는 있으나 **오이·감자·상추는 없다.** → 장기 적지 판정의 데이터 구조 자체가 작물군마다 다르다.
2. **개화기 저온(동해) 기준은 작물마다 다르다.** 배는 개화기 -1.7~-2.8℃로 원문 확인되나, **사과 개화기 동해온도는 이 출처에 없다(확인 불가).** 배 기준을 사과로 확대하면 안 된다.
3. 병해 예측(화상병 K-메리블라이트, 국가농작물병해관리시스템)은 **"감염 위험"이지 발병 확률·수확량 예측이 아니다.**
4. 국가농작물병해관리시스템의 위험 등급은 **정성 3단계(낮음/높음/매우 높음)**다. 임의로 점수·가중치로 바꾸면 안 된다.
5. **시설(오이) vs 노지**: 외부 기상데이터는 온실 내부 온·습도를 대변하지 못한다.
6. **지온·상대습도 지속시간·토양수분**은 공공 기상데이터로 근사하기 어렵다 → 현장 측정·사용자 입력 필요.
7. **품종 민감도 차이**(예: 감자 '수미'는 고온 둔감, '대서'는 민감)를 일반화하면 안 된다.
8. 착색적온·성숙기 기준 등은 **생육 단계에 종속**되므로 시점 정보 없이는 판단 보류.

## 3. 세 가지 항목 분리

### (A) 다섯 작물에 공통 적용해도 되는 항목
- **관측 원천 구분 자체**: "공공 기상데이터로 관찰 가능한 값(기온·강수·일조 등)"과 "현장 측정·사용자 입력이 필요한 값(지온·토양 pH·토양경도·온실 내부 온습도·엽면습윤 지속시간)"을 나누는 원칙은 다섯 작물 모두에 공통.
- **병해 위험 ≠ 발병률·수확량**이라는 한계 표기.
- **결측·이상치·기준 충돌 시 판단 보류** 원칙.
- 토양 pH가 어느 작물에서든 **현장 토양검정이 필요한 값**이라는 점(수치 자체는 작물별로 다름).

### (B) 작물별로 반드시 분리해야 하는 항목
- **장기 재배적지 등급표**: 사과·배만 공식 지도·등급표 존재. 오이·감자·상추는 없음 → 같은 로직으로 처리 불가.
- **온도 임계값 전부**: 연평균기온·생육적온·동해온도·비대적온·결구적온은 작물마다 상이(사과 연평균 7.5~11.5℃ vs 배 11.5~15.5℃ 등).
- **개화기/저온 피해 기준**: 배는 -1.7~-2.8℃ 확인, 사과는 확인 불가. 상호 대체 금지.
- **주요 병해와 그 조건**: 화상병(사과·배), 노균병(오이), 역병(감자), 팁번·추대(상추)는 병원·조건이 전혀 다름.
- **작형(노지/시설)**: 오이는 시설 중심, 사과·배는 노지, 상추·감자는 혼재 → 기온 데이터 해석 방식이 달라짐.

### (C) 추가 검증 없이는 서비스 판단에 사용하면 안 되는 항목
- **감자 역병의 정량 온·습도·지속시간 임계**(공식 원문 미확인, 확인 불가).
- **사과 개화기 동해온도**(확인 불가 — 배 값 전용 금지).
- **국가농작물병해관리시스템 등급의 수치·가중치 변환**(정성 3단계를 임의 점수화 금지).
- **저온요구량 1,200~1,500시간**(보도자료 스니펫만 확인, 전문·페이지·품종별 값 미확인).
- **오이 생육 온도**(제주 지자체 교육자료 — 전국·품종 일반화 전 원 매뉴얼 재확인 필요).
- **arccas 적지/가능지/부적지 경계값**: 공식 지표이나 **지도화·기후시나리오용**이므로, 개별 필지 미기후·토양을 대체하는 최종 판정으로 쓰면 안 됨.
- **NCPMS·화상병 예측을 "발생 확정/수확량 예측"으로 표시하는 것**.

## 4. 사실 / 연구자 해석 / 추가 조사 제안 구분

**사실(원문 확인/공식 스니펫):**
- arccas 사과·배 재배적지 등급표 수치, 사과 30℃↑ 비대 불량·착색적온, 배 개화기 동해 -1.7~-2.8℃ (원문 전체 확인).
- 오이 노균병 발병적온 15~20℃·6시간 100% 습도, 감자 괴경비대 14~18℃·27~30℃ 정지·pH 5.0~6.0, 상추 발아/생육 15~20℃·결구 10~16℃ (공식 도메인 스니펫).
- 화상병 병원균 25~29℃ 증식, K-메리블라이트 예측모형 존재, NCPMS 정성 위험등급 제공 (공식).

**연구자(본 조사자) 해석:**
- "오이·감자·상추가 공식 재배적지 지도에 없다는 사실은, 이 세 작물의 장기 적합성을 사과·배와 동일한 지도·등급 로직으로 처리할 수 없음을 뜻한다"는 판단은 데이터 부재로부터의 추론이며, 별도 공식 적지 자료가 존재할 가능성은 배제하지 못함.
- "시설 오이는 외부 기상과 내부 환경의 괴리가 커 기상데이터 단독 판정이 위험하다"는 것은 도메인 일반 원리에 근거한 해석.
- 병해 위험 지표를 발병률과 동일시하면 안 된다는 결론은 예측모형의 정의(감염 위험 산출)에서 도출한 해석.

**추가 조사 제안:**
- NCPMS 원 시스템(ncpms.rda.go.kr)에서 각 병해별 감염위험 산출 알고리즘·입력변수·등급 정의 원문 직접 확인.
- 감자 역병 예측모형(예: 기존 예찰 모델)의 **정량 임계**를 담은 공식 매뉴얼·논문 확보.
- 사과 개화기·유과기 저온 피해 임계온도(생육단계별)의 공식 원문 확보.
- 오이·상추·감자의 RDA 『농업기술길잡이』 원 PDF 페이지 대조(스니펫 값의 전문·품종·작형 조건 확인).
- 저온요구량의 사과·배 품종별 값 확인(보도자료 → 원 연구 추적).
- 착색적온·성숙기 기준의 품종 의존성 확인.
