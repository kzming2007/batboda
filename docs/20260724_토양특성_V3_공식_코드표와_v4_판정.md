## 1. 근거와 해석 범위

- [공공데이터포털 토양도 기반 토양특성 상세 정보 V3](https://www.data.go.kr/data/15144225/openapi.do?recommendDataYn=Y)의 공식 기술명세서 첨부파일에서 현재 화면·판정에 쓰는 코드표를 추출했다.
- [흙토람 토양 적성등급 설명](https://soil.rda.go.kr/soilact/recommend.do)에 따르면 1~4급지는 해당 용도로 이용할 수 있고, 5급지는 부적합하다. 등급은 토양의 생산 잠재력과 제한요인을 뜻하며 실제 수확량을 직접 예측하지 않는다.
- 밭 적성등급은 일반적인 밭 토양 이용능력이다. 감자 같은 개별 작물의 성공률·수확량·병 발생 확률로 해석하지 않는다.
- 현재 코드에는 아래 7개 표만 옮겼다. API가 제공하는 27개 특성 전체를 임의로 해석하지 않는다.

## 3. v4 단계 우선 판정

주결론은 보조 지수의 점수 경계로 만들지 않는다.

1. `현장 확인 필요`: pH가 작물 기준에서 크게 벗어나거나 결측·이상치인 경우, 밭 적성등급이 없거나 4~5급지인 경우
2. `조건부 적합`: 밭 3급지, pH 주의 구간, 또는 1~2급지라도 공식 저해요인이 있는 경우
3. `적합`: 작물별 pH 기준 안이며 밭 1~2급지이고 별도 저해요인이 없는 경우

숫자는 `100 - pH 운영 감점 - 밭 등급 운영 감점`의 비교용 보조 지수다. 밭 적성등급이 배수·경사·토심 등의 물리적 제한을 종합하므로 배수는 적합 지수에서 다시 감점하지 않는다. 배수는 선택 기간의 강수 위험을 설명할 때만 사용한다.

## 4. 평창 대표 사례

| 항목 | 실응답 코드 | 공식 해석 |
|---|---:|---|
| 배수 | 02 | 양호 |
| 유효토심 | 04 | 깊음, 100cm 이상 |
| 표토토성 | 04 | 세사양토 |
| 주토지이용 | 03 | 과수·상전 |
| 토지이용추천 | 03 | 과수·상전 |
| 밭 적성등급 | 04 | 4급지 |
| 밭 저해요인 | 02 | 경사 |

팜맵상 선택 필지는 밭이지만 토양도 주이용·추천은 과수·상전이다. 서로 다른 분류 목적을 화면에 함께 밝히고, 감자 pH `7.0`과 밭 4급지·경사 제한을 근거로 `현장 확인 필요`를 주결론으로 제시한다.

## 5. 검증 결과

- 공식 코드 변환, 1·3·4급지와 pH 경계, 핵심 결측, 배수 중복 산정 방지를 포함해 Vitest 30개를 통과했다.
- 560개 합성 시나리오에서 운영 감점 폭을 ±20% 바꿔도 단계 판정 변동률은 `0%`였다. 단계가 점수 임계값에서 분리됐기 때문이다.
- 같은 감사에서 선택 기간 위험 등급 변동률은 완화 `60%`, 보수 `10%`였다. 위험 기여도와 경계는 여전히 운영값이므로 후속 보정 대상이다.
- production build를 통과했다. 이 결과는 구현 안정성 검사이며 농업 현장 정확도 검증은 아니다.
- 같은 PNU 실데이터 재호출에서 연결 소스 `4/4`, 경고 없음, 배수 `양호`, 밭 `4급지`, 저해요인 `경사`, 주결론 `현장 확인 필요`, 보조 지수 `28`을 확인했다.
