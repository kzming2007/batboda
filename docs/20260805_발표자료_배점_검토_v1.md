# 2026-08-05 발표자료 배점 검토 v1

> 대상: `발표/20260805_밭보다_본선발표_v1.pptx` (10장) · `docs/20260805_발표대본_v4.md`
> 배점: 기획 30 · 구현 30 · 운영 가능성 25 · 프로젝트 발표 15
> 이 검토는 **자기 채점이 아니다.** 각 항목의 심사 질문에 슬라이드가 답을 갖고 있는지만 본다.

## 결론

**구현 30과 발표 15는 근거가 슬라이드에 있다. 기획 30과 운영 25는 각각 한 군데가 비어 있다.**

비어 있는 두 곳은 아래 3절에 적었다. 둘 다 **슬라이드 한 줄로 메울 수 있고, 새 주장이 아니라 이미 가진 사실을 옮기는 일**이다. 다만 둘 다 팀 확인이 필요하다.

## 1. 항목별 대응

### 기획 30점 — 문제를 제대로 정의했는가

| 심사 질문 | 어디서 답하는가 | 상태 |
|---|---|---|
| 누구의 문제인가 | S1 — 초보 귀농인, 심는 것은 평균이 아니라 농지 하나 | 답한다 |
| 문제가 무엇인가 | S2 — 자료가 없는 것이 아니라 네 기관·단위로 흩어져 대조가 안 된다 | 답한다 |
| 왜 이 접근인가 | S3 — 다섯 고리. 경계 확인부터 근거 추적까지 | 답한다 |
| **그 문제가 실제로 있다는 외부 근거는** | **없다** | **비어 있다 → 3-1** |

문제 정의가 **논리로만** 서 있다. 사용자 인터뷰, 상담 창구 문의 사례, 귀농 통계 중 어느 것도 슬라이드에 없다. 확인되지 않은 수치를 쓰지 않기로 한 결정의 결과이고, 그 결정 자체는 맞다. 다만 그 결과 기획 항목이 **"말은 되는데 확인은 안 된 문제"** 로 들릴 여지가 남는다.

### 구현 30점 — 실제로 만들었는가

| 심사 질문 | 어디서 | 상태 |
|---|---|---|
| 돌아가는가 | S4 — 배포본 라이브 70초 | 답한다 |
| 데이터가 실제로 이어지는가 | S4 — 경계 → 필지번호 토양 → 좌표 예보를 화면에서 연속으로 | 답한다 |
| 판정 논리가 있는가 | S5 — 같은 농지, 작물에 따라 과수 4급지 / 밭 3급지 | 답한다 |
| AI가 무엇을 하는가 | S6 — 판정은 규칙, 설명은 AI, 검사 실패 시 규칙 문장 | 답한다 |
| 검증했는가 | S6 — 13파일 115건 · 560 시나리오 주 판정 변동 0/0 | 답한다 |

**이 항목이 가장 강하다.** 다섯 질문 모두 제품 화면이 근거다. 도해로 대체한 장이 없다.

S5가 특히 중요하다. **작물을 바꾸면 공식 등급 자체가 갈린다는 것은 무대에서 실물로 보일 수 있는 유일한 판정 논리 증거**이고, 심사위원이 즉석에서 다른 작물을 골라 확인할 수 있다.

### 운영 가능성 25점 — 계속 굴러가는가

| 심사 질문 | 어디서 | 상태 |
|---|---|---|
| 외부 의존이 끊기면 | S7 — 소스별 대체, 2026-08-03 인증 차단 실경험 | 답한다 |
| 사용자를 속이지 않는가 | S7 — 실시간 / 검증 스냅샷 / 시연 자료 세 상태 구분 | 답한다 |
| 누가 왜 다시 오는가 | S8 — 사건 단위 세 시점, 즐겨찾기 | 답한다 |
| 한계를 아는가 | S9 — 조회율 7.0%, 3일 예보, 관측소 6.45km, 현장 미검증 | 답한다 |
| **지역을 넓힐 때 비용이 어떻게 되는가** | **질의응답에만 있다** | **비어 있다 → 3-2** |

S7의 「겪은 일」이 이 항목의 핵심이다. **장애 대응을 가정으로 말하는 팀과 실제로 겪고 경로를 확인한 팀은 다르게 들린다.**

빠진 것은 확장 비용이다. `행정구역별 정적 DB를 새로 만들지 않는 구조`라는 사실이 **대본 v3 질의응답에만 있고 슬라이드에 없다.** 질문이 안 나오면 이 근거는 쓰이지 않는다.

### 프로젝트 발표 15점 — 5분 안에 전달되는가

| 심사 질문 | 대응 | 상태 |
|---|---|---|
| 시간을 지키는가 | 282초 · 여유 18초 | 설계됨 |
| 한 장에 한 주장인가 | 열 장 모두 제목이 주장이고 제목이 그 장의 전부 | 지켜짐 |

## 2. 금지 규칙 준수 확인

내용설계 v1의 「전 슬라이드 공통 금지」를 하나씩 봤다.

| 금지 | 결과 |
|---|---|
| 예선 문장·2026-07-26 캡처 재사용 | 지켜짐 — 캡처는 전부 새로 잡는다 |
| 경쟁팀·기관 기능 부재 주장 | 지켜짐 — 흙토람은 자료 출처로만 나온다 |
| `정확한 추천` `수확량 예측` `유일한` `운영비 0원` `도입 확정` | 지켜짐 — 슬라이드·노트 전문에 없다 |
| 과수·논 등급 미반영을 한계로 | 지켜짐 — S5의 강점으로 썼다 |
| 응답시간·후보 건수·위험 라벨·모델 버전 고정 | 지켜짐 — 어느 장에도 없다. 노트에 「화면 값을 읽는다」로 적었다 |
| 장식 도형·아이콘 나열·카드 그리드·아키텍처 도해 | 지켜짐 — 모든 근거 자리가 제품 화면 조각이다 |

**S3의 화살표는 장식이 아니다.** 다섯 고리가 병렬이 아니라 순서라는 사실을 나타낸다. 순서가 실제로 있으므로(경계를 확인하지 않으면 토양을 못 부른다) 구조 표시로 본다.

**S6의 각주 한 줄이 이 덱에서 가장 중요한 문장일 수 있다** — `코드 회귀와 산식 민감도 근거이며, 현장 정확도 검증이 아닙니다`. 115건과 560 시나리오를 정확도로 읽히게 두면 과장이 되고, 이 한 줄이 그것을 막는다. **발표에서 이 문장을 빼면 안 된다.**

## 3. 비어 있는 두 곳

### 3-1. 기획 — 문제의 외부 근거 (팀 결정 필요)

**지금 상태로도 발표는 성립한다.** 논리가 명확하고, 없는 근거를 만들지 않은 것은 S9의 태도와 일관된다.

다만 두 가지 중 하나는 가능하다.

| 안 | 내용 | 위험 |
|---|---|---|
| A. 그대로 둔다 | 문제 정의를 논리로만 세운다 | 기획 항목이 확인 안 된 가설로 들릴 수 있다 |
| B. 우리가 겪은 것을 근거로 쓴다 | 개발 중 대관령 표본에서 **258필지 중 18건만 산도가 조회됐다**는 사실 자체가 "자료가 내 농지로 이어지지 않는다"의 실측 근거다. S2에 한 줄로 넣는다 | 없다 — 이미 가진 실측이고 S9에서 이미 말한다 |

**B를 권한다.** 새 주장이 아니다. S9에서 한계로 말하는 같은 숫자를 **S2에서는 문제의 증거로 먼저 쓰는 것**이다. 같은 사실이 문제 제기와 한계 고백 양쪽에서 쓰이는 것은 모순이 아니라 일관이다.

넣을 문장 — S2 하단:
> 실제로 대관령 표본에서 토양 산도가 조회된 농지는 258필지 중 18건이었습니다.

### 3-2. 운영 — 확장 비용 (팀 결정 필요)

`행정구역별 정적 DB를 새로 만들지 않는 구조`를 S7 또는 S8 슬라이드에 한 줄로 올린다. **질의응답에만 두면 질문이 안 나올 때 이 근거가 사라진다.**

넣을 문장 — S8 하단 (실증 제안 상자 아래):
> 지역을 넓힐 때 행정구역별 정적 DB를 새로 만들지 않는 구조입니다.

**금액이나 「비용이 사실상 0」으로 바꾸지 않는다.** 구조까지만 말한다. v3 0절이 그렇게 정했다.

## 4. 발표 전에 반드시 남은 일

우선순위 순이다.

1. **캡처 13건.** 슬라이드의 근거 자리가 전부 점선 틀로 비어 있다. **이것이 지금 유일한 차단 요소다.** 배포본에서 잡아 얹고 틀을 지운다. 조건은 내용설계 v1 3절.
2. **리허설 1회 이상.** 특히 S4 라이브 70초와 S3 다섯 낱말. 282초 설계는 아직 검증되지 않았다.
3. **배포본 3회 연속 성공 기록.** 04까지 라이브로 갈지 03에서 닫을지를 이 기록으로 정한다.
4. 3-1·3-2 두 줄 추가 여부 결정.
5. 아침 수치 재확인 — 대본 v4 4-1절.

## 5. 이 검토가 판단하지 않은 것

- **실제 점수.** 심사위원의 기준과 다른 팀의 수준을 모른다.
- **캡처의 가독성.** 프로젝터에서 읽히는지는 캡처를 얹은 뒤에만 알 수 있다.
- **발표 시간의 현실성.** 리허설 전이다. 282초는 설계값이고 실측이 아니다.
