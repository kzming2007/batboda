# 화면 4페이지 분리와 리포트 키워드 강조

> 작성일: 2026-07-25
> 요청: 팀이 지목한 UI 5건. 한 화면에 쌓던 구조를 페이지로 나누고, 자료 나이와 리포트 가독성을 보강한다.
> 단일 기준 문서는 `docs/RISE_AI_해커톤_예선_준비_통합.md`이며 충돌 시 기준 문서를 따른다.

## 1. 결론

**한 화면 스크롤 구조를 4페이지로 나눴다.** `자세한 근거`와 `LLM 기반 리포트`는 접기(`<details>`)를 없애고 독립 페이지로 옮겼다. 판정서에는 접기가 남아 있지 않다.

검증: `tsc --noEmit` 무오류, Vitest 41/41, ESLint 무경고, production build 통과. 데스크톱·375px 네 페이지 모두 가로 넘침 없음.

## 2. 페이지 구조

| 단계 | 페이지 | 내용 |
|---|---|---|
| 01 | 농지·작물·기간 | 지도, 대표 농지, 01-B 농지 확인, 작물, 기간, 데이터 모드 |
| 02 | 농지 환경 판정서 | 판정, 이유 한 문장, 3열 근거, 먼저 할 일, 쉬운 설명 |
| 03 | 자세한 근거 | 토양·기온 대조, 예보, 농지 확인표, 최근 관측, 판정 방식, 계산 과정, 사용한 자료 |
| 04 | LLM 기반 리포트 | 초보자용 자연어 예시 문안 |

상단 `phase-nav`가 4단계 스텝 표시를 겸한다. 분석 전에는 02~04가 비활성이고, 현재 페이지는 딥그린으로 반전 표시한다. 각 결과 페이지 하단에는 다음으로 볼 화면을 고르는 카드(`page-jump`)를 뒀다.

페이지가 바뀌면 스크롤을 맨 위로 올린다. 이전 화면의 스크롤 위치를 물려받으면 새 페이지가 중간부터 보이기 때문이다.

**영상 촬영에 유리한 변화다.** 60초 안에서 스크롤로 훑는 대신 화면 전환으로 구간을 끊을 수 있다. 다만 구간마다 클릭이 하나 늘어나므로 대본에서 전환 시점을 미리 정해야 한다.

## 3. 항목별 처리

### 3-1. 01-B 농지 후보 목록 스크롤

후보가 356건까지 나와 화면이 아래로 계속 늘어났다. 목록에 `max-height: 268px`(560px 이하 232px)와 `overflow-y: auto`를 적용해 목록 안에서만 스크롤되게 했다. 스크롤 영역임을 알 수 있게 얇은 스크롤바를 남기고, 후보가 4건을 넘으면 `목록 안에서 스크롤해 N개를 모두 볼 수 있습니다. 지번을 검색하면 더 빠릅니다.` 안내를 붙였다.

`overscroll-behavior: contain`으로 목록 끝에서 페이지가 함께 밀리지 않게 했다.

### 3-2. 농지 확인 후 판정서 페이지로 전환

분석이 끝나면 결과를 아래에 덧붙이지 않고 02 페이지로 넘어간다. 기존 `scrollIntoView` 호출을 페이지 전환으로 바꿨다. 판정서 머리글의 `조건 다시 설정`은 앵커 링크에서 01 페이지로 돌아가는 버튼으로 바꿨다.

### 3-3. 자세한 근거 독립 페이지 + 양쪽 패딩

접기를 없애고 03 페이지로 옮겼다. 토양·기온 근거와 예보 섹션은 좌우 패딩이 0이어서 글이 페이지 경계에 붙어 있었다. 두 섹션에 `26px 28px 30px` 패딩과 흰 배경·테두리를 줘서 각각 하나의 판으로 읽히게 했다. 820px 이하 `22px 20px`, 560px 이하 `18px 14px`로 줄인다.

### 3-4. 기준시각 확대와 자료 나이 판단

기준시각을 14px 보조 글자에서 **17px 고정폭 값**으로 올리고, 라벨(`검정 시점`·`발표 시각`)을 위에 작게 얹었다.

그 아래에 **이 자료가 그 나이여도 괜찮은지**를 한 줄로 적는다. 자료마다 `오래됐다`의 의미가 다르기 때문이다. 경과 기간만 보여주면 판단에 도움이 되지 않는다.

| 자료 | 실측 기준시각 | 표시한 나이 판단 | 상태 |
|---|---|---|---|
| 팜맵 | 2022-12-30 | 판독 영상 기준으로 3년 6개월 지났습니다. 필지 형상과 지목은 잘 바뀌지 않아 그대로 씁니다. 다만 최근 형질변경은 반영되지 않을 수 있습니다. | stable |
| 토양검정 V2 + 토양특성 V3 | 2025-05-02 | 검정 후 1년 2개월 지났습니다. 산도·유기물은 아직 참고할 수 있는 값으로 봤습니다. 토성·유효토심은 나이와 무관합니다. | stable |
| 단기예보 | 2026-07-25 20:00 KST | 오늘 발표된 예보입니다. | fresh |
| 농업기상 관측 | 2026-07-18–2026-07-24 | 최근 7일 관측이라 지금 상태를 그대로 반영합니다. | fresh |

화학성이 36개월을 넘으면 `aging`으로 바뀌고 `심기 전 간이 검정으로 다시 확인하는 편이 안전합니다`를 붙인다. 화학성이 아예 없는 필지는 `토양도의 물리 성질은 잘 변하지 않아 기준시각이 오래돼도 그대로 씁니다. 산도는 조회되지 않았습니다.`로 적는다.

상태별로 왼쪽 세로선 색을 달리했다. `fresh` 딥그린, `stable` 회색, `aging` 골드다.

**36개월은 공식 재검정 주기가 아니라 이 서비스의 운영 기준이다.** 공식 주기를 확인하기 전까지 수치를 공식 근거로 표기하지 않는다.

### 3-5. LLM 리포트 독립 페이지 + 키워드 강조

접기를 없애고 04 페이지로 옮겼다. `시연용 예시 문안 · 생성 제공자 미연결` 배지와 고지 문단은 그대로 유지한다.

**강조 규칙을 화면이 스스로 정하지 않는다.** 리포트를 만드는 쪽(`lib/report/showcase.ts`)이 강조할 표현 목록을 함께 내보내고, 화면은 그 문자열을 찾아 색만 입힌다. 화면이 임의로 중요한 말을 고르면 근거 없는 강조가 생긴다.

색은 이미 확정된 판정 색 규칙을 그대로 쓴다.

| 종류 | 색 | 대상 | 실측 예 |
|---|---|---|---|
| `value` | 골드 | 실제 조회한 값 | `pH는 6.9`, `2급지`, `평균 22.8℃`, `물빠짐은 약간 양호`, `겉흙은 세사양토` |
| `official` | 딥그린 | 공식 기준 | `상추 공식 권장 범위 6.5–7.0`, `공식 적온은 15–20℃` |
| `caution` | 클레이 레드 | 주의·한계 | `저해요인은 저습`, `강수확률이 60%`, `위험도는 주의로`, `수확량이나 성공 가능성을 말하지 않습니다` |

배경 옅은 색 + 아래쪽 2px 밑줄로 표시하고, 본문 아래에 색 뜻을 적은 범례를 뒀다. 색만으로 구분하지 않게 강조는 굵기도 함께 올린다.

85-61전·상추 사례에서 12곳이 강조된다(value 4 · official 2 · caution 6).

긴 표현을 먼저 매칭해 짧은 표현이 앞서 잘라먹지 않게 정렬한다. 본문에 없는 표현은 강조 목록에서 자동으로 빠진다.

## 4. 남은 확인

- 강조 밀도가 적절한지 팀 검토가 필요하다. 12곳은 한 화면 기준이며, 늘리면 강조가 무의미해지고 줄이면 가독성 이득이 준다.
- 04 페이지의 예시 문안은 pH와 밭 적성등급이 모두 조회된 필지에서만 열린다. 열리지 않는 필지에서는 이유를 적고 비운다.
- 1분 영상 대본에서 페이지 전환 시점을 확정해야 한다. 전환이 3회(01→02→03→04) 들어간다.
